# PQR Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a UI-free core that reads the Coomeva PQR workbook, maps it to one case schema, applies a value dictionary, recomputes business days, and stores cases in SQLite.

**Architecture:** Pure domain functions do not touch the filesystem. An Excel adapter returns raw rows. An import pipeline maps headers, applies the dictionary, flags bad dates, and writes through a repository interface. SQLite is the first repository; a later HTTP API can sit on the same interface. No UI, no auth, no web server in this plan.

**Tech Stack:** Node.js 20+, TypeScript 5, Vitest, exceljs, better-sqlite3.

## Global Constraints

- No UI, no HTTP server, no CSS, no React in this plan.
- The workbook is an input file, not the system of record.
- Canonical columns are the 2025/2026 set. 2024 rows use the same fields; missing refund columns stay null.
- Store both the original catalog text and the official text. Dashboard code later reads the official text.
- If the dictionary has no entry, the official value is the trimmed original. Do not invent merges.
- Recompute `diasSolucion`. Ignore the spreadsheet formula result.
- Business days follow Excel `NETWORKDAYS.INTL(start, end, 1, holidays)`: Saturday and Sunday are weekends, both endpoints count when they are workdays, and a result below -5 becomes 0.
- A date whose calendar year is below 2024 or above 2100 is invalid. Do not compute days from an invalid date.
- Excel serial dates convert with the 1899-12-30 epoch (the same conversion that yields 2025-01-01 for serial 45658).
- Sheet names matching `PQRs` plus a four-digit year are case sheets. Do not read any `Festivos` sheet.
- Holiday dates are an injected `readonly string[]` of ISO dates. This plan does not call `https://calendariosnacionales.com/co/api/`. The CLI passes an empty list. A later plan will load that list from the API.
- Personal data (name, email, free text) stays in the local SQLite file. The core makes no network calls.
- Dictionary file format is CSV with header `field,from,to`. Allowed `field` values: `area`, `fuente`, `tipo`, `tema`.
- Lookup key: trim, collapse internal whitespace, Unicode NFD, strip combining marks, uppercase.

```ts
export function lookupKey(value: string): string {
```

```ts
const MIN_YEAR = 2024;
const MAX_YEAR = 2100;

export function excelSerialToIso(serial: number): string {
  const utc = Date.UTC(1899, 11, 30) + Math.round(serial) * 86400000;
  return new Date(utc).toISOString().slice(0, 10);
}

export function parseDateCell(
  value: string | number | Date | null,
): { iso: string | null; invalid: boolean } {
  if (value === null || value === "") return { iso: null, invalid: false };
  let iso: string | null = null;
  if (typeof value === "number" && Number.isFinite(value)) iso = excelSerialToIso(value);
  else if (value instanceof Date && !Number.isNaN(value.getTime())) {
    iso = value.toISOString().slice(0, 10);
  } else if (typeof value === "string" && /^\d{4}-\d{2}-\d{2}$/.test(value.trim())) {
    iso = value.trim();
  }
  if (!iso) return { iso: null, invalid: true };
  const year = Number(iso.slice(0, 4));
  if (year < MIN_YEAR || year > MAX_YEAR) return { iso: null, invalid: true };
  return { iso, invalid: false };
}
```

```ts
function eachDate(startIso: string, endIso: string): string[] {
  const dates: string[] = [];
  const cursor = new Date(`${startIso}T00:00:00Z`);
  const end = new Date(`${endIso}T00:00:00Z`);
  while (cursor <= end) {
    dates.push(cursor.toISOString().slice(0, 10));
    cursor.setUTCDate(cursor.getUTCDate() + 1);
  }
  return dates;
}

function span(from: string, to: string, holidays: ReadonlySet<string>): number {
  let count = 0;
  for (const iso of eachDate(from, to)) {
    const day = new Date(`${iso}T00:00:00Z`).getUTCDay();
    if (day === 0 || day === 6) continue;
    if (holidays.has(iso)) continue;
    count += 1;
  }
  return count;
}

export function businessDays(
  startIso: string,
  endIso: string,
  holidays: readonly string[],
): number {
  const set = new Set(holidays);
  const raw = startIso <= endIso ? span(startIso, endIso, set) : -span(endIso, startIso, set);
  return raw < -5 ? 0 : raw;
}
```
