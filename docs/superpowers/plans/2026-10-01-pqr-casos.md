# PQR Case Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Operate PQRS in the app: the queue older than 10 business days, close rate by type, cumulative curves by area, the full case table, and create plus close.

**Architecture:** Domain functions compute age, rate, and curves without touching disk. SQLite stores cases and a `holidays` table. `createSummaryServer` renders HTML for `/`, `/casos`, `/casos/nuevo`, and `/casos/:id/cerrar`. `GET /summary` stays an aggregate JSON document.

**Tech Stack:** Node.js 20+, TypeScript 5, Vitest, better-sqlite3, `node:http`, the existing `public/dashboard.css`. No new dependencies.

## Global Constraints

- Excel import remains `npm run import` and still **replaces every case**, including creates and closes made in the app. It also stores the holiday dates it loaded. `replaceAll` itself still only replaces cases.
- A new case requires fecha inicial, área, ID de orden, asociado, correo, fuente, tipo, tema, and motivo. Fecha de solución and texto de solución are close-only.
- Área, fuente, tipo, and tema go through `Dictionary.official`. The row stores both the typed text and the official value.
- Open queue: `fechaSolucion === null`, a valid `fechaInicial`, and `businessDays(fechaInicial, today, holidays) > 10`. `today` is the `America/Bogota` calendar date. Saturday, Sunday, and stored holidays do not count. An invalid start date stays out of the queue.
- If `holidays` is empty, `openQueue` and `applyClose` throw `no holidays loaded`. `GET /casos?cola=vencida` responds 503 with “No hay festivos cargados. La cola no se puede calcular.” The summary KPI shows “Sin festivos” and `colaVencida` is `null` with `colaError`.
- Create and close call `ensureHolidayYears` for any year of the submitted date that is not already in `holidays`. That uses `https://calendariosnacionales.com/co/v1/${year}/nacionales.json` and `User-Agent: pqr-core`. A failed or empty year throws.
- Close rate: cerrados / total for the official tipo. Closed means `fechaSolucion !== null`. A null tipo is `(sin valor)`. `tasa` is the fraction `cerrados / entrados`.
- Area curves: cumulative count by `YYYY-MM` of a valid fecha inicial, grouped by official area and tipo. Null area or tipo is `(sin valor)`. Months are the union of months in that area, so a series stays flat when another type has the only case that month. Invalid or null starts are skipped.
- Curve clicks do not zoom inside the SVG. A point links to `/casos?area=&tipo=&mes=`. A series legend links to `/casos?area=&tipo=`. A close-rate row links to `/casos?tipo=`. The queue KPI links to `/casos?cola=vencida` even when the count is 0.
- The case table shows fecha inicial, fecha solución, área, ID de orden, asociado, correo, fuente, tipo, tema, motivo, solución, and días. Names, emails, and free text appear there. They do not appear in `GET /summary` or `GET /`.
- New ids are `app-` plus `crypto.randomUUID()`. `sheetYear` is the start-date year and `rowNumber` is `0`.
- Close date must parse with the same 2024–2100 rule as `parseDateCell`, and must not be earlier than `fechaInicial`. Saving sets `diasSolucion` from `businessDays`.
- Forms: each control has a `label`, an asterisk on required fields, the error under the field, and a summary with anchors. Inputs are at least 44px. Correo is `type="email"`. Dates are `type="date"`. An invalid create or close redisplays the form with the submitted values. Success is a 303 to `/casos`.
- Below 768px the sidebar moves above the content and the chart grids stack. The page does not scroll horizontally. The case table scrolls inside `.table-scroll`.
- Palette stays `#1E40AF` / Fira Sans / Fira Code. No dark mode in this step.
