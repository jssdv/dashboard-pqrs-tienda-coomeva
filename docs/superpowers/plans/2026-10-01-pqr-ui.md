# PQR Summary Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Show the dashboard summary as one local HTML page with the reference layout and only the data `summarize` already returns.

**Architecture:** `renderPage(summary)` returns a full HTML document. `GET /` on the existing summary server calls `summarize(repository.list())` and sends that document. `GET /dashboard.css` serves the stylesheet. There is no React app and no chart library. The browser never receives case rows.

**Tech Stack:** Node.js 20+, TypeScript 5, Vitest, `node:http`, one CSS file.

## Global Constraints

- Keep the reference shell: sidebar, title, four KPI cards, two chart cards, ranked lists, light background, wide card radius.
- Do not invent a calendar, upcoming tasks, team member, add-task button, illustration, or extra navigation items.
- The only nav item is `Resumen`, marked current.
- Colors: primary `#1E40AF`, accent `#D97706`, background `#F8FAFC`, foreground `#1E3A8A`.
- Fonts: Fira Sans for text, Fira Code for figures, with a system stack fallback and `font-display: swap`.
- Icons are one SVG stroke style. No emoji icons.
- Light mode only. Hover motion 150–300ms. Honor `prefers-reduced-motion`.
- Four indicators: total, abiertos, cerrados, días promedio (`—` when null). `fechasInvalidas` is a text line.
- `porMes` is vertical bars with the value written on each bar.
- `porTipo` is an SVG donut only when there are 1 to 5 keys and the count sum is above 0. Otherwise horizontal bars. A table with key and count always sits beside that chart.
- Área, fuente, tema, and año are horizontal bars with key and count visible.
- Total 0 shows `Todavía no hay casos importados` and `npm run import`.
- Names, emails, and free text never appear in the HTML.
- Below 768px the sidebar and the four cards stack in one column.
- Work on branch `feature/pqr-core`. One commit per task. Do not push.
